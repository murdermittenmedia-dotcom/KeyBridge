# TuneBat Analyzer reference

Source: https://tunebat.com/Analyzer

Key workflow finding: TuneBat presents a Song Key & BPM Finder where the user uploads complete audio files, analysis starts after upload, and consolidated key and BPM estimates appear after completion. The page describes browser-based analysis and says the results are estimates produced by tuned key/BPM algorithms. This is the reference model for Tunerite’s explicit capture-and-report workflow, while Tunerite remains a real-time mixer plugin that can only analyze audio routed into its buses.

Relevant scope distinction: TuneBat’s page also describes sentiment/energy/danceability/happiness analysis, but Tunerite’s requested sidechain design must keep beat analysis on the main input and vocal metrics on the isolated Vocal Input auxiliary bus.
